# Archiv: Probelauf E1–E5, 2026-09-02

Kompletter Testdurchlauf der fünf Entscheidungen auf einem Codestand, gebaut
von einem Subagenten vor dem eigentlichen Webinar. Beispieloptionen:

- E1 · A · Chat
- E2 · B · Beim Gesetz
- E3 · D · Nach Thema
- E4 · D · Die Seite selbst
- E5 · Suche und Filter (Rückfallwunsch)

Details und Bewertung siehe `docs/erkenntnisse.md`, Abschnitt "Über den
Komplett-Probelauf (2026-09-02)".

Inhalt:

- `+page.svelte` — der Endstand aus dem Probelauf, alle fünf Entscheidungen
  nacheinander verdrahtet. **Nur Referenz, nicht der Ausgangspunkt für den
  echten Live-Build.** `src/routes/+page.svelte` im Projekt ist wieder auf
  die leere Startseite (Stufe 0) zurückgesetzt.
- `rehearsal-e1.png` … `rehearsal-e5.png` — je ein Screenshot vom Ende
  jeder Entscheidung.
